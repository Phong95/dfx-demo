## Phase Goal

**As a** civil engineer cleaning up a structural DXF drawing,
**I want to** select unwanted entities, delete or hide them with undo/redo, and export a cleaned DXF that preserves everything untouched byte-for-byte,
**so that** I have a complete, usable load-clean-export workflow without needing AI.

<objective>
Wire the full select-delete/hide-undo/redo interaction loop end-to-end, from canvas click through state management to toolbar actions and properties panel display.

Purpose: Prove the cleanup interaction model works before adding the export pipeline (Plan 02-02). After this plan, the engineer can click-select or box-select entities, delete or hide them, undo/redo any action, and see entity details — the entire manual cleanup workflow except file export.

Output: Extended drawingStore with zundo undo/redo, canvas with click/shift-click/box-select and visual feedback (selection overlay, deleted filtering, hidden dimming), CleanupToolbar with action buttons and keyboard shortcuts, PropertiesPanel with entity details.

</objective>

Implement custom panning triggered by holding the Space key while left-dragging: add a spaceHeld ref tracking whether Space is currently pressed (listen for keydown/keyup on window, set true on Space down, false on Space up). Keep the existing handleWheel zoom handler unchanged (wheel zoom is unaffected). Keep the existing handleDragEnd handler but rename it since the stage is no longer natively draggable — the custom pan handler now calls setViewerTransform directly on mouseup.

    RUBBER BAND INTERACTION: Use local React state (useState) for the rubber-band rectangle, never the zustand store per RESEARCH Common Pitfall 5. On mousedown on the stage background (e.target is the stage, not a shape, and spaceHeld is false): record the starting screen-space point in a ref. On mousemove, if a start point exists, compute the rectangle from start to current pointer and set it into the local state variable. On mouseup, if a rubber band rectangle exists with width or height greater than 3 pixels (minimum threshold to distinguish a click from a drag):
    - Convert the screen-space rectangle to world (canvas) space using the inverse of the stage transform per RESEARCH Pattern 3: worldX equals (screenX minus stageX) divided by scale, worldY equals (screenY minus stageY) divided by scale. Compute worldMinX, worldMinY, worldMaxX, worldMaxY normalizing for negative width/height from right-to-left or bottom-to-top drags.
    - Iterate over all entities in dxfData.entities by index. For each entity: skip if its index is in deletedEntityIndices, skip if its layer is not visible in layerVisibility, call computeBoundsForEntity and skip if it returns null. Test full containment: the entity bbox minX is greater than or equal to worldMinX AND maxX is less than or equal to worldMaxX AND minY is greater than or equal to worldMinY AND maxY is less than or equal to worldMaxY. Collect matching indices.
    - Call setSelection with the matching indices array.
    - Clear the local rubber band state.
    If the movement was below the 3-pixel threshold, treat it as a click on empty canvas and call clearSelection (per D-01).

    RUBBER BAND VISUAL per UI-SPEC: Render a Konva Rect on a top non-listening Layer (above the selection overlay layer) when the local rubber band state is non-null. The Rect position and size come directly from the screen-space rubber band state (not world-space, since it should track the cursor on screen). Konva fires onClick only when there is no significant drag movement, so entity click-to-select continues to work correctly alongside the rubber band system.
