## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, swatch-to-name gap in layer rows |
| sm | 8px | Compact spacing: tree indent step, badge padding |
| md | 16px | Default spacing: panel section padding, row internal padding |
| lg | 24px | Section padding: sidebar top/bottom padding, empty-state block spacing |
| xl | 32px | Layout gaps: toolbar icon-button hit target (square) |
| 2xl | 48px | Major section breaks: toolbar/header height |
| 3xl | 64px | Page-level spacing: empty-state vertical centering offset |

Exceptions:
- Sidebar fixed width: **320px** (8pt-aligned, matches CAD-tool panel convention — wide enough for layer name + count + swatch without truncating typical names).
- Layer/tree row height: **32px** (compact, since drawings can have 50+ layers / 10k+ entities and the list must stay scannable).
- Toolbar/header height: **48px** (matches 2xl token, houses zoom/fit controls and file-load action).

## Color

**Scope note:** this 60/30/10 contract governs UI **chrome only** (sidebar, panels, toolbar, buttons). Canvas-rendered DXF entity colors come from the file's own resolved BYLAYER/BYBLOCK ACI/RGB values (PARSE-02) and are rendered as-is — they are explicit domain data, never restyled to fit this palette.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#1E1E1E` (near-black neutral) | Canvas viewport background, app shell background |
| Secondary (30%) | `#2A2A2E` (elevated neutral) | Sidebar panel surface, toolbar surface, row hover background |
| Accent (10%) | `#3B82F6` (blue) | Primary CTA (Load DXF File button), selected/hovered entity highlight ring on canvas, active layer row indicator, focus rings |
| Destructive | `#EF4444` (red) | Unknown/unsupported-entity warning banner and count badge only — Phase 1 has no delete/hide destructive actions |

Accent reserved for: primary "Load DXF File" button, canvas hover/selection highlight color shift (CONTEXT.md decision), active-state indicator on the currently-clicked structure-browser row, and focus-visible outlines. Never used for static chrome (borders, dividers, default icon fill).

**Why a dark canvas:** AutoCAD's default model-space background is black; many standard ACI colors (white=7, yellow=2) are calibrated for visibility against a dark background. Rendering on a light canvas would make correctly-resolved colors (PARSE-02) appear washed out or invisible, undermining the "confidence that colors are correct" success criterion. Dark chrome throughout keeps the sidebar visually consistent with the canvas rather than clashing as a light panel next to a dark viewport.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Load DXF File" (button; also doubles as the drop-zone's clickable affordance) |
| Empty state heading | "No drawing loaded" |
| Empty state body | "Drag and drop a DXF file here, or click Load DXF File to browse your computer." |
| Loading state | "Parsing drawing…" (shown while the Web Worker parses; CONTEXT.md decision to keep UI responsive during multi-MB files) |
| Error state | "Couldn't read this file. Make sure it's a valid DXF file, then try again." |
| Unknown-entity warning banner | "{N} unsupported entity type(s) found — nothing was dropped, but these won't render. See Unknown section below." (only rendered when N > 0; satisfies PARSE-03) |
| Empty layers edge case | "No layers found in this file." |
| Destructive confirmation | None in this phase — layer visibility toggles (VIEW-03) are non-destructive view state only, not deletion; destructive delete/hide lands in Phase 2 (CLEAN-03) with its own confirmation contract. |

## UI Considerations

> Populated by the ui-phase UI-consideration probe (Step 9.5) and lifted by plan-phase's
> `## UI Considerations` lift rule via the identical rule as SPEC `## Edge Coverage`. Shape-rooted UI *state*
> coverage (empty / loading / error / populated / partial / overflow / zero-one-many / long-text).
> Empty-state and error-state COPY live in `## Copywriting Contract` above — this section covers
> state coverage and REFERENCES those rows rather than restating the copy (de-dup).

Elements classified: File-load drop zone (`form`), Layer panel (`list-collection`), Structure browser tree (`list-collection`), Canvas viewer (`media`/`interactive-control`), Unknown-entity warning banner (`static-content`).

Applicable state considerations resolved: 13 covered, 3 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | file-load drop zone, layer panel, structure browser | ✅ covered | Before any file is loaded, the empty-state screen (see Copywriting Contract "Empty state") replaces the sidebar/canvas entirely — no separate blank-panel state exists |
| empty | layer panel (post-load, zero layers) | 🧪 backstop | Malformed-but-parseable DXF with zero layer table entries shows the "Empty layers edge case" copy row instead of a blank list — verified via minimal-fixture test |
| loading | file-load drop zone, canvas | ✅ covered | Web Worker parse-in-flight shows the "Loading state" copy row with a spinner over the canvas area; sidebar stays in empty state until parse completes |
| error | file-load drop zone, canvas | ✅ covered | Parse failure shows the "Error state" copy row with a retry-by-reselecting-file path; user returns to the empty-state screen |
| error | canvas (worker crash/timeout on very large files) | 🧪 backstop | Same "Error state" copy path is assumed sufficient for worker-level failures, not just parser-level rejects — verified via oversized/malformed-fixture test |
| populated | layer panel | ✅ covered | Flat alphabetical list, each row = color swatch + name + entity count (CONTEXT.md decision); Show All/Hide All buttons for bulk ops |
| populated | structure browser | ✅ covered | Tree hierarchy layers > entity types > entities, virtualized from the start (CONTEXT.md decision) |
| populated | canvas | ✅ covered | Initial view is fit-to-extents (CONTEXT.md decision); hover highlights entity via accent color shift |
| partial | structure browser (entity-level render failures) | 🧪 backstop | A supported entity TYPE (e.g. malformed SPLINE control points) that fails to construct valid geometry is bucketed into the same "Unknown" section/count as unsupported types, with a distinct reason string — verified via malformed-geometry fixture test |
| overflow | layer panel (long layer names) | ✅ covered | Truncate with ellipsis at the 320px row width; full name via tooltip on hover |
| overflow | structure browser (long entity-type/layer names) | ✅ covered | Same truncation rule as layer panel (reference, not restated) |
| overflow | structure browser (10k+ entities) | ✅ covered | List virtualization (CONTEXT.md decision) handles overflow via scroll, not truncation |
| zero-one-many | layer panel | ✅ covered | Zero → empty-layers copy row (see backstop above); one → single row, Show All/Hide All remain functional as no-ops; many (50+) → sidebar scrolls internally past fixed height |
| zero-one-many | unknown-entity warning banner | ✅ covered | Zero → banner not rendered at all; one-or-many → banner + dedicated "Unknown" section with count (PARSE-03), copy row above |
| long-text | layer panel, structure browser (names) | ✅ covered | Same truncation + tooltip rule as overflow row above (reference, not restated) |
| long-text | loaded-filename indicator | ✅ covered | Truncate with ellipsis (end-truncate), full filename via tooltip on hover |
