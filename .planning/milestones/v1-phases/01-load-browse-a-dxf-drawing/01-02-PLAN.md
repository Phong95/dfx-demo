    Step 1 -- Create src/dxf/bulgeToArc.ts. Export bulgeToArcPoints(p1: {x,y}, p2: {x,y}, bulge: number, segments?: number): {x,y}[] per RESEARCH Code Examples. Otherwise compute theta as 4 * Math.atan(bulge), derive radius from chord length and theta, compute arc center from midpoint offset along the chord normal, generate interpolated points along the arc. When entity.fitPoints exists and has length > 0, return fitPoints (smoother approximation). Otherwise return entity.controlPoints.     Step 3 -- Create src/dxf/stripMTextFormatting.ts. Export stripMTextFormatting(raw: string): string per RESEARCH Code Examples. Replace \P with newline, \p[params]; with newline, \[letter][params]; formatting codes with empty string, escaped braces with empty string, \~ with space.

    ENTITY RENDERERS (steps 4-11): Each component accepts props: entity (typed per dxf-parser), color (string, pre-resolved hex), and optional onMouseEnter/onMouseLeave callbacks for hover. Each negates Y coordinates for the DXF-to-canvas flip. Each uses strokeWidth 1 and hitStrokeWidth 10.

    Step 4 -- ArcShape.tsx: Use a custom react-konva Shape with sceneFunc per RESEARCH Pattern 6. Call ctx.beginPath(), ctx.arc(entity.center.x, -entity.center.y, entity.radius, -toRadians(entity.startAngle), -toRadians(entity.endAngle), true), ctx.strokeShape(shape). DXF ARC angles are in degrees; convert to radians. Note: DXF angles are measured counter-clockwise from the positive X axis; the Y-flip inverts the arc direction, so negate the angles and set anticlockwise to true.

    Step 5 -- CircleShape.tsx: Use react-konva Circle component. Set x to entity.center.x, y to negative entity.center.y, radius to entity.radius, stroke to color, no fill.

    Step 6 -- LwpolylineShape.tsx: Walk entity.vertices pairs. For each consecutive pair, check if the current vertex has a non-zero bulge value. If bulge is zero, add a straight segment. If non-zero, call bulgeToArcPoints to interpolate the curved segment. Flatten all points into a single points array for a react-konva Line. Set closed to entity.shape (true when the LWPOLYLINE is closed). Negate all Y values.

    Step 7 -- TextShape.tsx: Use react-konva Text component. Set x to entity.startPoint.x, y to negative entity.startPoint.y, text to entity.text, fontSize to entity.height or 1 (DXF text height is in drawing units), fill to color (TEXT entities use fill, not stroke), rotation to negative entity.rotation (degrees, default 0). Apply the DXF Y-flip scaling so text reads correctly (scale Y by -1 on the Text component or its parent Group to counteract the canvas Y-flip, otherwise text appears mirrored).

    Step 8 -- MtextShape.tsx: Same approach as TextShape but first run stripMTextFormatting(entity.text) to clean the raw MTEXT content. Use entity.position instead of startPoint. Set width to entity.width for text wrapping if present. Handle entity.attachmentPoint for text alignment (1=top-left, 2=top-center, 3=top-right, etc.).

    Step 9 -- InsertShape.tsx per RESEARCH Pattern 3. Accept dxfData (full IDxf) as an additional prop or read it from the store. Resolve the block definition via dxfData.blocks[entity.name]. If block is null or undefined, render nothing (skip silently). Otherwise wrap the block's entities in a react-konva Group with position (entity.position.x, -entity.position.y), rotation (-entity.rotation degrees, default 0), scale (entity.xScale or 1, entity.yScale or 1). Recursively render each block entity using EntityRenderer. Beware: do not recurse infinitely on nested INSERTs -- add a maxDepth parameter (default 5) and decrement on each recursive call.

    Step 10 -- DimensionShape.tsx per RESEARCH Pattern 3. Accept dxfData. Resolve the anonymous block via dxfData.blocks[entity.block] (block names like "*D1", "*D2"). If block is null, render nothing. Otherwise render the block's entities (typically LINE, SOLID for arrowheads, MTEXT for dimension text) using EntityRenderer inside a Group. No additional transform needed for dimension blocks -- they are already authored in model-space coordinates.

    Step 11 -- SplineShape.tsx: Call flattenSpline(entity) to get the approximated polyline points. Render as a react-konva Line with the flattened points (negate Y values). Stroke with the resolved color.

    ENTITY DISPATCHER (step 12): Create src/components/CanvasViewer/entities/EntityRenderer.tsx.
